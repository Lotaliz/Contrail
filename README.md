## Principles

- **Evidence first** — 原始资料、来源陈述、综合判断与研究假设分层保存。
- **Traceable** — 关键事实回到来源，实验结论回到配置与原始输出。
- **Reusable** — 单篇阅读进入项目比较，跨来源知识沉淀为概念实体。
- **Lightweight** — Markdown、WikiLink 与只读校验组成最小研究工作流。
