# Quantifying Large Language Model Attacks Through the Lens of Model Cognition

## 书目信息与精读范围

- 会议：USENIX Security 2026。
- 原文：[[LLM-Wiki/raw/papers/2026-liu-quantifying-llm-attacks-model-cognition.pdf]]。
- 精读范围：摘要、引言、方法、全部核心实验、讨论、局限及附录中的池化和层选择说明。
- 术语边界：论文把逐层隐藏表示的变化称为“model cognition”，但其探针只能证明**与有害提示标签相关的特征可分**，不能证明模型具有人的认知、意图理解，也不能证明这些特征因果地控制生成；作者在 §3.1 和 §5 也明确限定了这一点。

## 研究问题与场景

### 核心问题

现有 LLM 安全评估多以最终输出“拒答还是服从”为准，因而无法区分两种机制：

1. 模型在内部根本没有识别出有害意图；
2. 模型中间层已编码安全相关信号，但这些信号在后续解码中被指令遵循/任务完成倾向削弱或覆盖。

论文据此研究：（1）安全相关特征在 Transformer 深度方向何时出现、传播和衰减；（2）不同攻击扰动如何改变这条逐层轨迹；（3）能否融合少量互补层，在生成前形成轻量、白盒的攻击检测器。

### 研究场景

- **离线审计/红队诊断**：模型开发者批量检查越狱提示在各层的响应，定位安全识别与最终执行脱节的位置。
- **在线生成前门控**：在可访问宿主 LLM 隐藏状态的白盒部署中，读取选定层的最后一个 prompt token 表示，在生成有害 token 前拒绝输入。
- **多类攻击与分布迁移**：覆盖 NSFW 改写、隐晦提示、语义保持扰动、prompt injection 和多轮逐步暴露有害意图。
- **不适用场景**：闭源 API、无隐藏状态接口的第三方模型，以及不愿承担宿主 LLM 前向计算的独立 guard 场景。

## 主要创新点与贡献

1. **把“攻击是否成功”从输出标签扩展为逐层表示轨迹。** 论文训练每层的低容量 MLP 探针，绘制安全相关特征随层深出现、增强或衰减的图谱，从而把“识别—执行脱节”变成可量化问题（§1、§3.1、Fig. 3–5）。
2. **提出 Attack Consistency Index（ACI）。** ACI 汇总原始—扰动提示在各层最后 token 隐状态的平均余弦距离，并分别考察相对原有害提示的 `ACI_harmful` 与相对语义匹配良性提示的 `ACI_benign`。它是比较表示漂移的诊断统计量，不是攻击强度的理论界（§3.1、§3.3、Table 2）。
3. **提出互补多层 Sentinel。** 作者根据不同攻击策略下的层行为向量做相关性去冗余，选取高可分、低冗余的非相邻层，拼接其表示后训练小型分类器；这针对“没有任何单层对所有扰动都稳健”的实证现象（§3.3、Algorithm 1、Fig. 4、Fig. 6）。
4. **同时承担诊断与防御。** Sentinel 不只输出攻击标签，还保留“哪一层、哪类扰动导致漂移”的解释入口；论文将其定位为开发者/审计者的内部补充防线，而非替代黑盒内容审核（§5）。
5. **给出自适应白盒攻击证据。** 单层探针平均约 13.1 步即可被攻破；多层目标因跨层梯度冲突而更难同时优化，作者报告攻击成功率从 17% 上升到最高 58% 后停滞，加入表示一致性约束后未收敛（§4.2、Fig. 8–9）。这支持“多层互补优于单层”，但不能推出对所有自适应攻击不可攻破。

## 核心方法

### P1：逐层安全画像

- 对 decoder-only LLM 的每一层提取 prompt **最后一个 token** 的隐藏状态；附录消融显示 mean pooling 会稀释靠近生成边界的信号。
- 每层训练一个两层 MLP（100 个隐藏单元）区分有害/良性提示，以 AUROC 衡量表示可分性。
- 探针结果只表示相关特征可由简单分类器读出，不表示这些特征被生成机制因果使用。

### P2–P3：表示漂移与 ACI

- 构造原始有害提示与扰动版本的配对，计算各层余弦相似度/距离。
- 扰动覆盖元素插入、句法前缀/后缀、虚构/艺术语境、角色扮演和主题转移。
- `ACI_harmful` 小表示仍保留原有害语义；`ACI_benign` 小表示更靠近匹配良性表示。Table 2 把攻击概括为两类：低漂移的“伪装”与高漂移的“破坏”。

### P4：Sentinel 构造

- 用每层在多种扰动下的毒性检测率形成行为向量；先保留高可分层，再用层间相关性贪心去冗余。
- 拼接被选层的最后 token 隐状态，训练一个低容量多层分类器进行二分类。
- 线上仍需宿主 LLM 前向传播，只是避免生成完成后再审核。

## 实验设置与数据

- **训练数据**：NSFW-56k 中 1,000 条有害提示；由 OpenAI o1 生成 1,000 条结构匹配的“家庭场景”良性描述；8:2 划分（§4）。
- **评测数据**：SneakyPrompt（200）、I2P（4,700）、MMA、Labelled（5,350）、PIJ（5,000）、ChatAlpaca 与 Multi-turn Jailbreak；分别考察对抗鲁棒性、域外泛化、越狱与多轮鲁棒性（§4）。
- **模型规模**：摘要声称覆盖 7 个 1.5B–72B 开放权重模型；正文主要逐层结果覆盖 Qwen2.5、Qwen3、Llama 3.1/3.2 等模型，72B 用于效率测量。
- **基线**：黑盒 Judge、NSFW Text Classifier、Llama-Guard-3-8B；白盒 HiddenDetect、JBShield、GradSafe。
- **指标**：Accuracy、AUROC、Precision、Recall/TPR、F1，尤其报告 TPR@0.1%/1% FPR；另报告 ACI 和自适应攻击成功情况。
- **环境**：单张 NVIDIA A100、PyTorch 2.6.0（§4）。

## 主要结果与证据定位

### 作者主张及直接证据

- **中间层可分，但不等于“理解”**：跨模型的中间深度（约全栈 50%–70%）常有 AUROC > 0.9；Qwen3-4B 的安全相关可分性从首个 Transformer 层明显出现并随深度稳定（§4.1.1、Fig. 3；§5）。
- **层敏感性互补**：前缀扰动可能在早层仍被检测、在深层骤降；后缀更常破坏中层，没有一个层对所有扰动都稳健（§4.1.2、Fig. 4）。
- **ACI 揭示伪装机制**：句法前缀和元素扰动可同时保持很低的 `ACI_harmful`（<0.1）并向良性区域移动（`ACI_benign` 约 0.21–0.27），说明表面伪装并未消除有害相关内部特征（§4.1.3、Table 2）。
- **多层检测优于所列基线**：Table 3 中不同宿主模型的 Sentinel 平均 Accuracy 为 0.905–0.937（Qwen2.5-7B 为 0.905；Qwen3-8B 与 Llama3.1-8B 为 0.937），平均 AUROC 为 0.878–0.929；对 PIJ 的 Accuracy 为 0.9117，相比 JBShield 0.7183（§4.1.4、Table 3–4）。
- **多轮结果**：未额外训练时，在论文的 Multi-turn Robustness 混合集上达到 97.0% Accuracy（§4.1.4）。
- **效率口径**：Qwen2.5-72B 的全层表示提取 8.37 分钟、分类器训练 10.84 分钟、存储 6.10 GB；线上门控约 50 ms/提示（§4.3、Table 5）。这不是包含宿主模型完整前向的独立 5M guard 成本。

### 对“94%/99%”数字的解释

- “最高 99%”是特定层/数据或论文总结中的上界，不应解读为所有模型和基准都达到 99%。
- “自适应攻击下 >94%”来自作者设定的攻击与检测口径；Table 3 的跨数据平均结果更适合描述常规基准表现。
- “假阴性减半”是相对生成级拒答/输出判断的论文摘要结论，不等价于固定 FPR 下所有基线都减半。

## 优点

- 明确分开“内部识别信号存在”与“最终安全行为执行”，研究问题比单纯输出检测更有机制解释力。
- 用多层去冗余选择回应单层探针可被针对的问题，并给出黑盒、白盒和自适应攻击三类比较。
- 报告低 FPR 指标、训练/存储/延迟和 72B 规模测量，较贴近安全门控部署。
- 作者主动限制因果与认知解释，避免把 probe 可读出性直接等同于模型理解。

## 局限、失败条件与证据缺口

- **白盒与宿主依赖**：必须访问指定模型内部层；换架构/版本通常要重新提取表示并训练，无法直接用于闭源 API。
- **不是独立轻量模型**：`<5M` 只计算 Sentinel 头，宿主 LLM 前向成本仍在；对“安全判别器压缩”只能作为小头证据，不能与 5M 独立 encoder 横向比较。
- **训练分布可能过窄**：训练只用 1,000 条 NSFW-56k 有害提示和 o1 合成的家庭场景负例，结构匹配虽减弱词汇捷径，但不足以排除数据源/风格捷径。
- **自适应攻击覆盖有限**：主要是 GCG 风格离散后缀；“跨层梯度冲突”是当前攻击设置的观察，不构成不可规避性证明。
- **因果性不足**：probe 读出的相关方向未通过干预、causal tracing 或反事实编辑证明会控制拒答。
- **架构与任务外推未验证**：MoE、多模态、encoder–decoder、多语言、工具调用和长程 agent 轨迹仍是开放问题（§6）。
- **效率边界不完全统一**：约 50 ms 的硬件、batch、是否包含 hidden-state hook/传输与宿主前向计时边界需在复现前核对。

## 与同方向工作的横向关系

- 相比单层概念激活的 JBShield，本文强调跨层轨迹和互补融合；Table 4 在 PIJ 上提供了直接比较。
- 相比 Llama-Guard-3-8B 或 NSFW 文本分类器，它依赖宿主内部表示，参数头更小且可在生成前判别，但部署权限更严格。
- 与 [[LLM-Wiki/research/ai-safety-systems-security-venues/papers/2025-qu-vlm-unsafe-concepts.md|VLM 跨模态不安全概念]] 共同说明：安全失败不必等同于输入内容完全未被感知；前者在 LLM 深度上分解“识别—执行”，后者在 VLM 任务上分解“感知—对齐”。

## 对当前研究的启发（综合判断）

1. 若压缩安全 guard，应同时测最终分类与**中间安全信号保留**；只对输出蒸馏可能复制最终决策而丢失对新攻击的互补层信息。
2. 可把多层教师特征蒸馏到独立小 encoder，比较“宿主内小头”与“独立小模型”的 Accuracy/TPR@固定 FPR、宿主成本、端到端延迟和迁移性。
3. 候选假设：跨层去冗余选择比只蒸馏最后层更能维持域外攻击召回。该假设尚无本地实验支持，不进入正式 Motivation。

## 待验证问题

- 复现约 50 ms 时，计时是否包含宿主前向、跨设备拷贝、batch 和 tokenizer？
- 用同一低 FPR 阈值重算 Table 3/4 后，多层优势是否仍稳定？
- 更强的联合自适应攻击、连续 soft prompt、模型微调攻击能否绕过跨层冲突？
- 对安全表征做因果干预，是否能把“可检测”提升为“可执行的安全控制”？
