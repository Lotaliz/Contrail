# 政策文本指导图像安全审核的自适应分辨率

## 1. 从任务场景出发

图像安全审核服务接收图片 $I$、当前生效的文本政策 $P$ 和固定的输出要求，返回允许、拦截或对应的违规类别。同一张图片在不同政策下可能有不同正确答案。例如，物体是否存在只是视觉事实，是否允许出现、是否满足例外条件才决定审核标签。这里的文本是审核规则，不是与图片共同构成违规内容的用户请求。

研究总问题是：**如何让运行时政策指导视觉计算的压缩，在保持政策判定能力的同时降低真实审核时延？** 当前选择整图输入分辨率作为计算动作：先决定整张图片需要多少视觉 Token，再执行一次目标 Guard。不预设局部裁图、局部分辨率分配或小目标检测模块；也不把政策改写、增加风险图片或模型解释本身作为主要贡献。

降低输入分辨率可以同时减少视觉编码和后续语言主干的工作量，但会改变视觉信息、视觉序列长度和位置布局。这与完整视觉编码后的 Token 删除不是同一种操作。论文应准确说明执行位置，并与已有视觉剪枝方法在相同任务、质量约束和计时边界下比较。

本阶段的基本思路是：**研究不同分辨率如何改变模型读取、保留和使用政策相关视觉信息，再把经过验证的信号用于轻量分辨率选择。** 解释性分析服务于计算决策：需要说明为什么某些图像—政策条件可以压缩、哪些条件需要更多预算，以及错误属于哪一环节。

当前假设是：许多审核所需的判别信息在较小整图输入中已经足够，而部分退化来自这些信息在模型中的读取、传递或利用方式发生变化。它与“细节确实消失”“政策理解错误”“输出偏置变化”等解释并列，尚未被排他性验证。

## 3. 三个研究问题

| 问题 | 通俗含义 | 对应观察或检验 | 对预算选择的价值 |
|---|---|---|---|
| Q1：文本从哪里读取信息？ | 哪些文本位置、哪些层在关注图像及政策条款；分辨率改变了什么 | 分组注意力、逐层比较、输入顺序控制 | 寻找信息获取不足或路径改变的候选信号 |
| Q2：文本表征保留了什么？ | 关注过图像后，文本内部表示是否含有当前政策判定所需的信息 | 图像对照下的隐藏状态变化、受控线性探针 | 区分“读过”与“判别信息已形成”，寻找信息充分性的信号 |
| Q3：这些信息是否影响最终决定？ | 改变相关中间表示，审核答案或判别余量是否随之变化 | 状态替换、双向干预及对照 | 验证候选信号的决策相关性，减少依赖漂亮热图 |

三者不相互替代。注意力较高不能直接证明信息已经存储；探针能读出标签不能证明 Guard 使用了该信息；替换后能救回也不自动说明正常推理只依赖该路径。研究允许发现直接视觉读取与文本中介并存，或者在某种提示格式下文本中介不成立。

## 4. 共同分析设置

### 4.1 固定任务，改变整图预算

先冻结已经使用的 Guard 权重、政策文本、标签映射、提示格式和解码规则。已有工作负载包括 LlavaGuard/UnsafeBench 派生的政策审核数据，以及 PolicyShiftBench 的独立政策体系。分别在 Qwen3-VL 审核设置与 PolicyShiftGuard/PolicyShiftBench 设置中分析，记录各自真实模型版本、数据划分与政策处理方式；不推定用户当前 PolicyShiftGuard 的参数规模。两套政策体系分别报告，不强行映射类别，也不默认其政策经过相同压缩。

每套设置先选完整输入、近乎无损的静态上限，以及明显退化的更低上限。已有 60、75、40 仅为各自模型上的候选工作点。按实际合法网格和实际 Token 数记录输入，小图无需为达到上限而放大；同一请求预算落到相同网格时，不把它们当独立处理条件。

增加三种输入控制：原图与原网格、低清图片与小网格、同一低清图片插值回原网格。后两者帮助检查信息清晰度和网格处理的区别，但插值也改变像素统计，不能称为严格的“只改变 Token 数”实验。相同张量、相同网格的重复前向用于估计数值差异。

### 4.2 用政策标签和正确性分组

沿用已有图像、政策与标签，优先利用同图 pass/block 政策对，不要求重新标注大量概念或区域。标签是否对应当前政策是前提；有争议或多种合法类别的样本单列，不让模型自己的解释充当新 gold。

相对于完整输入，至少保留四组：两者都对、完整对低预算错、完整错低预算对、两者都错。先在变化样本和按类别、政策族、原始 Token 数匹配的稳定样本上做昂贵内部分析，再在全量约 3,000 条评测上检查输出曲线。探索样本的结论不能直接外推为总体发生率。

同一图片的政策变体按基础图片分组划分训练、开发和测试；探针及选择器也遵守这个边界。Bootstrap 等区间估计以图片为聚类单位，保留同图政策对；对未见政策泛化另设政策族隔离，不把同图多条记录当独立证据。

### 4.3 先建立可解释的输出参照

对于二元审核，令 $s_k(y)$ 为预算 $k$ 下合法 verdict 字符串的序列对数概率，定义正确判别余量

$$
m_k(I,P)=s_k(y)-s_k(\bar y).
$$

它表示当前政策的正确答案相对相反答案有多大优势。合法 verdict 的公共输出前缀、分词和多 Token 计分方式保持一致；只分析首 verdict，不把生成的真实答案喂回去后再解释其内部状态。多类别任务另报正确类别对最强错误类别的余量，以及二元允许/拦截结果。无效格式单列，二元余量不能替代类别正确率。

对同图的禁止政策与允许政策，分别计算各自正确余量，再看较弱一侧及两侧都正确率。这样能够发现：降低分辨率是增加漏检、增加误报，还是使模型对两种政策都给出相似答案。余量、NLL 是模型分数，不直接等于经过校准的错误概率。

## 5. Q1：观察信息读取位置与路径

首先导出真实输入的 Token 顺序和语义分段：图像、禁止条款、允许/例外条款、其他条款、任务指令、特殊 Token，以及首 verdict 前的最后输入位置 $D$。$D$ 用于预测第一个审核输出，不等于已经生成的 verdict Token。

因果语言模型中的文本只能读取它之前的位置。如果政策位于图像之前，其隐藏状态不能吸收后面的图像信息；此时重点应是 $D$ 对图像的直接读取、$D$ 对政策的读取，以及图像之后其他文本的作用。必要时把图像/政策顺序改变作为独立提示实验，不能悄悄换顺序后归因于分辨率。

注意力矩阵按“查询位置→被读取位置”解释。分别检查图像之后的文本→图像、$D$→图像、$D$→各类政策条款，避免把“某个文本被关注”误写成“该文本正在关注图像”。相关条款优先由已有政策规则和数据字段确定；无法可靠分组时使用完整政策段，不用模型热图反向定义正确条款。

跨分辨率同时报告组内注意力总量、每 Token 平均值和层/头分布。图像 Token 数、位置与 softmax 分母都在变化，任何单一归一化都不能把注意力变成可直接比较的“视觉信息量”。可增加注意力加权 value 向量的范数作为辅助，但仍需要后两步检验。

**主要图形：**固定颜色范围的“层×语义位置组”热图；四类正确性分组的逐层曲线及区间；同图两种政策下的对应差值。先看所有预选层或预先规定的层段，再在独立开发样本选头，避免只展示最显著的头。保存分组统计即可起步，不必为全量数据落盘完整的所有头注意力矩阵。

若提取注意力需要切换 eager 等后端，先核对输出与原 SDPA/高效后端的一致性；诊断时延不能替代实际部署时延。该问题的产出是候选信息路径及分辨率敏感位置，尚不是因果解释或在线选择规则。

## 6. Q2：检验政策判别信息是否保留在文本表征中

对相同语义文本位置比较各预算的隐藏状态，按文本身份对齐，不按包含图像偏移的绝对序号硬对齐。分别分析政策条款、图像后的任务文本和位置 $D$，不要把 $D$ 已形成的答案表征与一般政策文本混在一起。

先做固定网格的正确图像、自然错配图像及空白图像对照，必要时增加纯文本控制。隐藏状态发生变化说明对输入敏感，尚不能说明变化包含正确的视觉事实；空白图像可能偏离分布，结论需与自然图像对照核对。

随后冻结 Guard，用少量层上的线性探针预测已有的政策审核标签。比较正确图像、错配图像与纯文本条件，在图片和政策族隔离的划分上评估；若错配图像同样能预测，探针可能主要读取政策或类别先验。探针只使用首 verdict 前的状态，不读取 gold 回答或完整模型已经生成的理由。

重点是：低预算错误时，某层是否仍可读出正确政策判定；近乎无损预算是否保留这种可读性；政策翻转时，表征是否随当前规则产生可区分变化。状态余弦差异可作描述，单独的数值大小不定义信息丢失。

**主要图形：**各层探针在四类样本上的泛化表现；图像对照与分辨率对照下的状态变化曲线；正确判别余量与探针表现的对应图。若正确答案可被探针读出而最终 Guard 仍错，只能提出“信息存在但利用可能有问题”的候选解释，下一步检验其决策作用。

## 7. Q3：通过受控替换检验决策作用

在完整输入正确、低预算错误的同一图像—政策条件上，获取两个预算的中间状态，将完整输入中某层的一组图像后文本状态替换到低预算分支，继续执行后续模型，观察正确余量、答案及误报/漏检变化。这是本研究拟迁移的实验，不是已有论文已经证明的跨分辨率结论。

优先比较禁止条款、允许/例外条款和普通任务文本，并尽可能排除位置 $D$。若对应条款位于图像之前，不能把其替换效果解释为“转移了视觉信息”；应换用实际可读取图像的后续文本位置。直接替换最后一层 $D$ 很可能是在复制答案，只适合作为干预上限对照。

必需对照包括低预算→低预算的身份替换、数量匹配的无关文本位置、来自错误图片的高预算状态，以及对完整错低预算对样本做反向替换。保留负向效果与无效替换，不只报告成功救回，也不将恢复量截到 0–1 后掩盖损害。

跨预算替换存在位置编码、网格和状态分布差异。先用相同网格的图像对照验证替换接口，再做跨分辨率实验；替换之后重算受影响的后续路径和缓存，不沿用不一致的旧 KV。Qwen3-VL 等模型还需核对额外视觉注入路径，说明实际干预覆盖了什么。

必要时辅以特定读取边的注意力屏蔽，但屏蔽后仍能作答可能意味着启用了备用路径，并不说明被屏蔽路径原本无用。状态替换同样可能制造新的推理状态，必须与未干预观察及其他对照共同解释。

**主要图形：**“替换层×文本组”的有符号判别余量变化图；按错误方向统计的救回与新增错误比例。支持文本中介的证据应是特定、可重复且超过对照的变化，而非仅仅存在一次可救回替换。若文本状态替换无特异效果，应保留直接视觉路径等解释。

## 8. 从机制观察回到轻量分辨率选择

### 8.1 离线信号与在线输入分开

上述注意力、探针和状态替换主要用于离线诊断与监督生成。先运行完整 Guard 才取得的内部信号，不能免费用于这次请求的编码前分辨率选择。在线原型保持简单：一次低成本整图预览与政策编码，输出一个整图预算，然后运行一次目标 Guard；所有预览、文本编码、选择和缩放成本计入端到端。

可先用图像尺寸、长宽比、原始网格、预览特征，以及政策文本表示和已有规则字段作为输入。是否加入 OCR 或其他模型由实际净收益决定，不默认免费。离线教师信号只有在便宜预览中可预测、且对预算收益有增量解释力时才值得蒸馏。

### 8.2 先定义要预测什么

选择器应预测“这个图像—政策条件在各预算下的错误风险或升级收益”，而非图片本身有多危险。相同图片的不同规则可能需要相同预算，也可能不同；不强迫每次政策翻转都改变预算。

第一版可以为少量候选预算分别预测审核损失 $\widehat L_k(I,P)$，在开发集确定的质量约束与实测代价下选择预算。已有 gold 用于训练标签；完整输入错、低预算对的样本按真实标签保留，不无条件要求复制完整输入。预算质量曲线允许非单调，不自动把第一个正确预算以上的所有预算都标为充分。

解释指标的候选是政策两侧正确余量的保留、对正确图像的表征依赖，以及经替换验证的判别信息保留程度。先检查它们能否在控制原始 Token 数、类别、政策族后区分升级有益与无益样本，再判断便宜预览是否能预测。只有离线相关性而无法便宜预测的指标，保留为诊断结论，不硬接成在线模块。

用不含机制监督的轻量分类器、仅图像预览、仅政策和完整图文输入作消融。若加入政策没有增量收益，应如实收缩“政策指导预算”的主张，而不能仅因 Guard 读入了政策就宣称选择器也使用了政策。

### 8.3 质量与真实成本共同决定是否继续

强对照首先是开发集选定的固定上限整图缩放，以及同平均实测时延的简单预算策略，再比较已使用的 FastV、VisionZip、CDPruner 等方法。VisionThink、AdaptVision、ZOO-Prune、FEATHER 仍是用户选定的待补对照，需分别注明训练、额外调用与适配成本，不能记作已运行。

主要质量指标包括类别宏召回、危险召回、良性误报率、准确率、同图政策对两侧均正确率，以及压缩新增的危险→允许和允许→拦截错误。有连续分数时补充固定误报率下的危险召回；开发集固定阈值，不在测试集逐方法挑最有利点。

效率记录完整 time-to-verdict、均值及 P50/P95，并拆分预处理、预览/选择器、视觉编码、LLM prefill 和短输出 decode，固定硬件、batch、后端、预热与重复次数。不同方法用实际网格、实际输入 Token 和实际时间对齐。减少 Token 却被前端抵消，不算有效加速。

若固定 60/75 已接近时延下限，而更低预算收益很小，自适应模块优先检验能否在接近该成本时救回重要错误；不预设仍有大幅加速空间。若在同成本下不能超过强静态上限，解释性研究仍可留下可信发现，但不足以证明新加速方法成立。

## 9. 下一步安排与完成标准

1. **归档输入与输出条件。** 固定每个模型—数据集的样本清单、政策、真实网格、checkpoint 和计分方式；整理逐样本预算曲线及四类正确性分组。当前会话数字在原始产物核验前维持“用户报告”状态。
2. **先完成 Q1 的定位。** 在变化样本与匹配稳定样本上抽取分组注意力，核查因果顺序和后端一致性，找出值得继续分析的位置；不用热图直接判定充分性。
3. **依次验证 Q2 和 Q3。** 对预选层做受控探针和状态替换，保留直接路径、文本中介、提示依赖及无法解释的负结果。先在一套设置把接口跑通，再在已使用的第二套模型—政策体系验证关键结论，不先扩大模型与数据数量。
4. **决定是否训练选择器。** 仅对有稳定增量证据、可由便宜输入预测的信号开展轻量训练；从少量整图档位开始，使用独立开发集确定约束，最终测试集用于一次确认性评测。

每阶段执行时再创建对应实验目录，记录实际代码版本、配置、命令、种子、设备、预算、原始输出和失败。本页仅记录基本研究思路与最小验证逻辑，不表示这些实验已执行，也不指定尚未测量的数值非劣界或预期提升。

当前可检验的候选贡献是：**对政策条件审核的分辨率敏感性给出经过对照的决策解释，并证明该解释能帮助便宜的整图预算选择，在真实成本约束下维持政策适应与安全质量。** 仅观察文本注意力迁移、探针可分类，或提出普通预算预测网络，都不足以单独支持这一贡献。

## 10. 来源、支持范围与待验证主张

| 依据 | 已有材料支持什么 | 本研究的迁移边界 |
|---|---|---|
| [VTW](https://arxiv.org/abs/2405.05803)，摘要及信息迁移分析 | 作者观察早层视觉信息向后续文本迁移，并据此撤出深层视觉 Token | 不能推定所有 Guard 或所有任务都依赖文本中介；也不是输入降分辨率实验 |
| [LLaVA-Mini](https://arxiv.org/abs/2501.03895)，摘要、§3–4 | 研究早期图文融合，并训练预融合模块以压缩视觉输入 | 新增训练模块的能力不等于冻结 Guard 已具备的压缩能力 |
| [Pathways of Visual Information Flow](https://arxiv.org/abs/2607.03358)，§2–4 | 区分图像直达与文本中介；路径受任务/提示影响，干预可能触发备用路径 | 提供 Q1–Q3 的方法参照；跨分辨率、可变政策审核及在线选择效果均待验证 |

| [[LLM-Wiki/research/visual-token-pruning/papers/2026-song-policyshiftguard.md\|PolicyShiftGuard / PolicyShiftBench]] | 运行时政策审核、同图边界对和两侧正确评估 | 支持任务与标签协议；不证明低分辨率足够或文本中介成立 |
