# M3

来源：[arXiv 2405.17430v1](https://arxiv.org/html/2405.17430v1)。复用已有 source_id，快读摘要、引言、方法图、§3、Tables 1–2、消融及结论；未下载新 PDF 或复现。

**作者方法：** 将完整视觉编码器输出池化为 576、144、36、9、1 个视觉 Token，共同训练视觉编码器和 LLM，并平均每个样本各尺度分类损失。实现共享 checkpoint 的多粒度输入；仍执行完整视觉编码，不直接节省输入像素侧 ViT 计算。

**证据：** Table 2 的 LLaVA-NeXT-M3 在 MMBench 用 576 Token 为 67.96；使用测试 gold 选最少正确 Token 的 oracle 为 74.35、平均 8.90 Token。该结果是不可部署的上界，不是作者已实现自适应预测器。§5 明确有效预算预测器仍是缺失能力。

**项目判断：** 可迁移共享多预算 Guard 适配的思路，以及离线最小充分配置标签；不能宣称随机预算采样复现全部尺度平均损失，亦不能把 oracle 增益当实际 C5 效果。若复现嵌套视觉表示而非借鉴配置监督，需进一步 deep-read。
