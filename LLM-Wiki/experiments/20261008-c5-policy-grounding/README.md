# C5 结果分析

## 目的与状态

分析用户提供的已完成 C5 实验，制定单局部框下的政策指导改进。此次只读取报告、核对论文与计算汇总差值，未运行模型、访问报告列出的实现或逐样本输出。下述数字均为用户报告，未标为本地 reproduced。用户明确不继续多框路线。

## 原始证据与数据

原始报告已按字节复制到 [[LLM-Wiki/experiments/20261008-c5-policy-grounding/raw/20261008-c5.md|C5 原始记录]]，原件与副本 SHA256 相同：`a50e9a5afc6f30fd451e1b1fb965c05a1c594a577a735abf5ef6e28def33ebbd`。原始记录不改写；其中相对代码/产物路径仅是作者索引，本次未核实，不建立这些文件的 Wiki 链接。

工作集为 `policy-guard-short64-dynamic-v1`：原 train 10,378 行，清除与 dev 图像重叠的 809 行后为 9,569 行；dev 401 行；冻结 test 2,967 行。输入为图像、动态政策、固定任务提示，输出 A–J，A 为当前政策下 Safe。名称中的 short64 不足以确定每条政策实际长度、例外结构或全部模板字段；本次报告未提供该分布。不能用历史 v3 的 PolicyShiftBench 规模描述本次 C5 已评测范围。

## 方法与环境

5% 名义预算按原视觉 Token 数规划合法二维网格，C5 全量实际平均预算为 5.0792%。33 条路线包括 Global100、16 个 75/25 全局＋单局部框、16 个 50/50 全局＋单局部框；全部沿用逐样本严格 Token 上限。Router 读取 128×128 缩略图与完整当前政策，五层 CNN 输出 4×4×128 特征，字节 embedding 加两层文本 Transformer，经 cross-attention 预测 profile 和区域。

Guard 从 B0 初始化，在 9,569 行上做三轮全参数低预算/多视图恢复训练。测试相同 C5 路线，恢复 Guard 宏召回 0.4974，原 B0 Guard 为 0.3483。不同 router 使用其配套 Guard，跨系统差值不能全部归因于 router 或文本输入。

**用户后续训练设置补充（本次对话，未检查代码）：** 恢复 Guard 已使用全部政策翻转样本，优化目标只有分类交叉熵。后续 gain 回归/政策收益差分建议属于 router 训练，不据此认为 Guard 缺少翻转样本，也不将可训练全局路径的 loss 作为负奖励加入 Guard 的 CE。

**用户补充的 router 目标：** 预算分配软标签 KL、区域选择标签 KL、路线得分排序损失与标签反转惩罚四项。新增建议是在同一 teacher 代价下统一为完整路线收益，比较纯 Huber 与 Huber＋联合路线 KL；第四项先沿原定义保留。未检查其具体计算，不将其自动视为同图政策边界配对损失。没有替换后的实验结果。

时延环境：H20-3e、FlashAttention 2、batch 1；每法 8,901 条计时记录。模型 revision、训练种子、逐样本 logits、路线缓存、完整依赖与 P95 未在本报告归档。此次没有新增命令执行记录可用于复现实验。

## 原始汇总与派生差值

| 条件 | 宏召回 | Unsafe recall | Safe recall | E2E 均值 |
|---|---:|---:|---:|---:|
| B0，完整视觉 | 0.6564 | 0.8882 | 0.9186 | 84.72 ms |
| VisionZip95，原 B0 Guard | 0.5513 | 0.7666 | 0.9401 | 80.34 ms |
| Global100-cap，C5 配对静态条件 | 0.4405 | 0.7421 | 0.8997 | 46.01 ms |
| C5 | 0.4974 | 0.7624 | 0.9141 | 58.90 ms |
| V5，无文本 router | 0.4807 | 0.7477 | 0.8861 | 56.56 ms |

由表直接相减：C5 对 Global100-cap 宏召回 +5.69 pp、Unsafe recall +2.03 pp、时延 +12.89 ms；对 V5 宏召回 +1.67 pp、Unsafe recall +1.47 pp；对 B0 宏召回 −15.90 pp、Unsafe recall −12.58 pp。C5 的二分类 benign FPR 为 $1-0.9141=0.0859$。这些只是报告汇总的派生差值，没有配对显著性结论。

C5 NLL 为 1.1972，略高于配对 Global100-cap 的 1.1936；分类质量改善不等于平均 gold likelihood 同步改善。报告的分项均值合计约 47.88 ms，而总均值 58.90 ms，存在约 11.02 ms 尚未说明的差额；需检查计时边界、未列阶段或非加性统计，不能指定其原因。

## 支持与不足

- 支持：单局部框在相同预算下可补回部分风险证据；低预算输入适配贡献明显；C5 相对若干候选有实际系统速度优势。
- 不足：尚未证明政策语义对路线选择的稳定因果贡献；同图异策选择同一路线既不能证实政策使用，也不能证伪政策使用。
- 不足：仍有明显完整视觉质量损失，不能写成“安全性能基本保持”。VisionZip 更高质量、Global100-cap 更快，C5 是一个折中工作点。
- 边界：多框 P1 未过门禁的负结果保留，不能概括成所有多框方法不可行；本研究后续按用户约束保留单局部框。

## 后续实验假设与停止条件

**用户后续定性观察（本次对话）：** 检查 C5 错/B0 对的样本后，发现全局图过于模糊、局部选择了错误区域，以及大尺度或狭长证据无法被 1/16 单格覆盖的情况。没有提供各类型样本数、区域标注或新 oracle，故只记录为定性证据。该观察使单框尺度/宽高比覆盖诊断提前；固定框库全部失败尚不能直接判定是预算极限。

H1：同图异策的相对路线收益监督可比普通逐行 soft-target 更准确学习政策改变的效用。H2：匹配布局的局部像素干预能区分真实证据增益与输入布局效应，并提供 router 新监督。H3：条款级、实际参与评分的中间量可提高路由可审计性；其语义与性能均待验证。

固定 C5 恢复 Guard、预算和数据 split，先用训练集内部的基础图像分组 pilot。保留原 33 路线作对照，先比较加入横/竖/较大单框的候选 oracle，仍至多一个 local crop；政策损失/结构在同一候选库内逐项比较。官方 test 只留作方案冻结后确认，已公开的三个 test 实例只用于问题说明。保存失败和负结果。若降低 oracle regret 后仍不能改善独立安全指标，或解释通道可随意修改而路线不变，则不提升相应主张。
