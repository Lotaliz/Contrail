# 实验目录

每个实验使用独立目录：`experiments/YYYYMMDD-short-name/`。

建议内容：

```text
YYYYMMDD-short-name/
├─ README.md        # 从 templates/experiment.md 复制
├─ data/            # 小型原始或处理后数据
├─ outputs/         # 模型输出与图表
└─ scripts/         # 可复现脚本（如需要）
```

所有结果说明应链接到对应研究项目的 `overview.md`；必要时再与相关论文笔记互链。
