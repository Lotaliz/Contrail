# 研究工作流共同契约

## 证据分层

- 原始来源：论文 PDF、网页快照、数据和原始实验输出。
- 来源陈述：作者明确写出或数据直接显示的内容，必须能回到来源位置。
- 综合判断：由多篇来源比较得到，必须列出支持与反例。
- 研究假设：尚未充分验证的解释或预测。
- Motivation：有证据的研究缺口与具体场景约束的交集。

不得把后一层伪装成前一层。

## 写入边界

- raw 只保存原件，不直接改写。
- 一篇论文对应一条 sources.yaml 记录；需要阅读内容时创建一份 paper-note。
- concepts 只保存跨论文复用的实体，不保存单篇论文摘要。
- 调研比较、研究缺口和 motivation 放在 research 项目中。
- 实验原始输出与解释分离。
- 大文件不在库中重复保存；记录路径、版本和校验值。

## 通用完成条件

- 新来源已登记且 ID 唯一。
- 新文件符合 schema，日期、状态和标签有效。
- 关键事实能回到来源或实验。
- 不确定内容已标为 hypothesis、TODO 或待验证。
- 相关链接、索引和按日期记录的 CHANGELOG 已更新。
- 已运行 Wiki 校验器。
- 工作流未执行任何 Git 操作。
