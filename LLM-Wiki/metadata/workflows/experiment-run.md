# 实验执行流程

## 触发

运行、复现、评测、比较、消融、调试或分析研究实验。

## 实验前

- 创建 experiments/YYYYMMDD-short-name。
- 从实验模板填写问题、假设、基线、变量、数据版本、指标和成功标准。
- 记录代码提交、模型版本、依赖、硬件、随机种子和预算。
- 区分探索性实验与确认性实验。

## 执行

- 保存实际命令和最终配置。
- 原始日志、输出和中间结果不可由总结覆盖。
- 失败、中断、超时、OOM 和人为终止都记录状态与原因。
- 未经用户授权不扩大算力、下载受限数据或执行高成本批量运行。

## 分析

- 先记录原始结果，再计算派生指标。
- 区分观察、统计推断和解释。
- 与预先定义的基线和成功标准比较。
- 报告方差、样本量、异常值处理和缺失运行。
- 单次运行不得提升为普遍结论。

## 完成

- README 能让他人定位数据、配置、代码和输出。
- 结论链接到相关论文与概念。
- 对假设、comparison 或 motivation 的影响已明确记录。
- 执行 Wiki 收尾流程。
